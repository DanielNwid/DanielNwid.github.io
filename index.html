Projects

Daily Sales KPI Email Automation

↗

Every morning at 08:00, an n8n workflow queries Postgres, works out revenue, orders, margin and refund rates against the prior day, last week and the 7-day average, and emails the report with no analyst in the loop. I backtested the alert rule on a year of data before shipping it: a fixed percentage threshold fired on one day in five, so I switched to a z-score against the 28-day mean, which fires about four times a year.

n8n Postgres Gmail SQL

Sales Warehouse: Nightly Multi-Source Load to BigQuery

↗

An n8n pipeline that lands orders, finance targets and the public-holiday calendar in one BigQuery warehouse every night, then builds models and eight reconciliation checks against the source. A run that fails a check still logs itself and then fails on purpose. Going incremental cut a normal night from 163 seconds to 53. The Looker Studio report shows FY26 targets behind pace, with June at 87% attainment.

n8n BigQuery Postgres Google Sheets Looker Studio SQL

Electricity Price Forecasting for Germany

↗

A machine learning model that predicts German electricity prices one hour ahead, using 54 features across 19,056 hours: demand, wind and solar output, and cross-border power flows. It catches the direction of price moves most of the time and about half of the big spikes. The strongest signal is the Germany-Luxembourg price, followed by Czech and Dutch neighbours.

Python Machine learning Forecasting

Northwind Sales Performance and Customer Segmentation

↗

An analysis of Northwind Traders' orders, customers and products, covering data cleaning, feature engineering, customer segmentation and shipping efficiency, presented in an interactive Power BI dashboard. The High segment drives about 76% of revenue, and order volume peaks at the end of 2014 and early 2015.

Python Power BI Pandas Jupyter

Solana Sentiment Analysis for Fraud Detection

↗

Built for the Messari Crime Fighting AI Toolkit Hackathon. The project scores X sentiment and post volume for Solana using Messari's Signal API, then flags days where mood shifts unusually fast, which can signal a pump-and-dump. Across eight days in April 2025 it flagged six as suspicious.
